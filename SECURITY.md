# Security Policy

## Supported Versions

Since DT Engine is a proprietary, in-house game engine developed by Neofilisoft, security updates and patches are actively maintained for the latest development branches and active milestones.

| Version | Supported          |
| ------- | ------------------ |
| Beta    | :white_check_mark: |
| Alpha   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Neofilisoft. If you discover a security vulnerability, exploit, or a critical bug within DT Engine (such as a buffer overflow, arbitrary code execution, or asset parsing vulnerabilities), **please DO NOT disclose it publicly**.

As this is a proprietary engine, please report any suspected vulnerabilities by contacting the internal development team directly or via your designated Neofilisoft technical contact/lead.

**When reporting a vulnerability, please include:**
- A detailed description of the vulnerability and its potential impact.
- Clear steps to reproduce the issue (including any malicious `.asset` files or scripts used).
- The version/commit hash where the vulnerability was found.
- Any potential mitigation or proposed fix if you have one.

We will review all reports confidentially and issue an internal patch or hotfix as quickly as possible.
